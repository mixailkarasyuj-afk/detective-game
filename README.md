# Перехват

Детективная игра для компании за одним экраном. Комиссар Громов ведёт дело, говорит за свидетелей и тайно ведёт беглеца по карте, а игроки командой вычисляют и арестовывают преступника.

## Запуск

```bash
npm install
npm run dev     # разработка, http://localhost:5173
npm run build   # сборка в dist/ (статический сайт, сервер не нужен)
```

## Устройство

- `src/game/engine.ts` — правила: генерация дела, улики, свидетели, слухи, ход беглеца, арест.
- `src/packs/*.json` — города: карта, подозреваемые, свидетели с характерами, преступления, слухи. Новый город — новый JSON.
- `src/packs/catalog.ts` — витрина: бесплатный Сонный Яр и платные города.
- `src/packs/unlock.ts` — открытие пакета кодом. Пока проверка идёт в браузере; перед запуском продаж её нужно перенести на сервер вместе с оплатой.
