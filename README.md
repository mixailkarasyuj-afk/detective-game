# Беглец

Детективная пати-игра для компании за одним ноутбуком. Ноутбук играет беглеца и свидетелей, игроки — команду следователей.

## Запуск

```bash
npm install
npm run dev     # разработка, http://localhost:5173
npm run build   # сборка в dist/ (статический сайт, сервер не нужен)
```

## Устройство

- `src/game/engine.ts` — правила: генерация дела, действия (допрос, осмотр, патруль), ход беглеца.
- `src/packs/*.json` — «пакеты городов»: карта, подозреваемые, преступления, свидетели. Новый город — новый JSON.
- `src/packs/catalog.ts` — витрина: бесплатный пилот и платные пакеты.
- `src/packs/unlock.ts` — открытие пакета кодом. Пока проверка идёт в браузере; перед запуском продаж её нужно перенести на сервер вместе с оплатой.
